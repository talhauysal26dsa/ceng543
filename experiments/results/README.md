# Experiments Results Directory

This directory stores JSON result files from ablation experiments.

## Structure

```
results/
├── prompt_ablation_msmarco_baseline.json
├── prompt_ablation_msmarco_cot.json
├── prompt_ablation_msmarco_fewshot.json
├── prompt_ablation_hotpot_baseline.json
├── prompt_ablation_hotpot_cot.json
├── prompt_ablation_hotpot_fewshot.json
├── prompt_ablation_fever_baseline.json
├── prompt_ablation_fever_cot.json
└── prompt_ablation_fever_fewshot.json
```

Results are automatically generated by `run_prompt_ablation.py`.
